Base de datos y scripts del servidor

Tablas preparadas en MySQL (sql/poscafe.sql) y scripts del lado del servidor en PHP (php/) con manejo de sesiones ($_SESSION).

Tablas de la base de datos (poscafe)

Descargar script SQL (poscafe.sql)
Tabla SQLCamposRelacionesScript del servidor / Pantalla
usuarios id, nombre, correo, contrasena (hash bcrypt), rol Una venta pertenece a un usuario. php/usuarios.php, php/sesion.php — Usuarios y Iniciar sesión
categorias id, nombre Una categoría tiene varios productos. php/productos.php — Productos y Punto de venta
productos id, nombre, descripcion, precio, existencias, categoria_id Pertenece a una categoría y aparece en muchos detalles de venta. php/productos.php — Productos e Inventario
ventas id, fecha, usuario_id, subtotal, descuento, total, metodo_pago Pertenece a un usuario y tiene varios detalles. php/ventas.php — Punto de venta y Historial
detalle_ventas id, venta_id, producto_id, nombre_producto, nota, cantidad, precio_unitario Une una venta con los productos vendidos. php/ventas.php, php/carrito.php — Punto de venta y Historial

Scripts del lado del servidor y sesiones

  • php/conexion.php: inicia la sesión (session_start()) y conecta con MySQL mediante PDO.
  • php/sesion.php: conserva y muestra el nombre del usuario en $_SESSION['usuario'] durante la navegación.
  • php/carrito.php: gestiona el carrito de compras en $_SESSION['carrito'] (añadir, listar, modificar cantidad/información y eliminar productos).
  • php/productos.php, php/usuarios.php y php/ventas.php: consultan y actualizan las tablas en MySQL.
